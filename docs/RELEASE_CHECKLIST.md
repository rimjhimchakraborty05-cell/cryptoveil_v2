# CryptoVeil release gate

Do not call a build complete until automated Windows packaging, extension-pairing recovery, evidence verification, and a manual first-run check on a Windows desktop have passed.

An automated smoke test does not prove that every native UI component, browser page, or endpoint sensor works on a real user's machine.

Release requirements: installation without admin rights, clear startup errors, browser connection with one-use code, visible sensor failures, harmless live tests, dated signed evidence export, safe restart, no fabrication of detections, and full source attribution for the Windows build.

    BROWSER CONNECTION

    Connect your extension

    1. Load the CryptoVeil extension

      Open your browser’s Extensions page, enable Developer mode, choose Load unpacked, and select this folder.

    2. Generate a one-use pairing code

      This code expires in five minutes. Keep the application open.

    3. Enter the code in the extension popup

      Give the browser a name and select Pair with application. Collection starts once pairing succeeds.
